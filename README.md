### 🚀 Featured Engineering Case Studies

#### 🫁 01. PulmoScan — AI-Powered Pulmonary Diagnostic System
> **Medical Computer Vision & Explainable AI (XAI)**

* 🛑 **Engineering Challenge**:
  * **Class Imbalance & Low Contrast**: Radiograph datasets exhibit severe class imbalance between rare pulmonary pathologies and healthy scans, coupled with low local image contrast that hides early lesions.
  * **Model Opacity**: Standard deep learning probability outputs act as "black boxes", limiting clinical trust among radiologists.

* 💡 **Technical Solution**:
  * Integrated **Contrast Limited Adaptive Histogram Equalization (CLAHE)** to normalize radiograph contrast and sharpen tissue boundary definitions.
  * Employed **Weighted Focal Loss** with backbone transfer learning (ResNet/EfficientNet) to penalize misclassifications on hard positive samples.
  * Generated **Grad-CAM (Gradient-weighted Class Activation Mapping)** heatmaps overlaid on X-rays to display visual region attributions for transparent diagnostic validation.

* **Tech Stack**: `PyTorch` • `OpenCV` • `Grad-CAM` • `Scikit-Learn` • `Python`

#### 🎭 02. Emotion Drift Detection System
> **Natural Language Processing & Sentiment Acceleration Dynamics**

* 🛑 **Engineering Challenge**:
  * **Static Model Limitations**: Traditional sentiment analysis evaluates messages in isolation, failing to track subtle, cumulative emotional decay in multi-turn conversations.
  * **Delayed Escalations**: Standard classifiers trigger warnings only after customer frustration has already peaked, missing proactive intervention opportunities.

* 💡 **Technical Solution**:
  * Designed a **temporal sliding-window transformer algorithm** to calculate sentiment **trajectory**, **velocity**, and **acceleration** over consecutive timestamped utterances.
  * Extracted contextual embeddings using fine-tuned **Hugging Face Transformers** to measure cosine distance shifts between baseline neutral states and negative drift vectors.
  * Built an automated escalation trigger that alerts leads before customer satisfaction collapses.

* **Tech Stack**: `Python` • `Hugging Face Transformers` • `PyTorch` • `NLP` • `Pandas`

#### 👁️ 03. Shastra Eye — Real-Time AI Surveillance Pipeline
> **Edge Computer Vision & Real-Time Analytics**

* 🛑 **Engineering Challenge**:
  * **High-Resolution Stream Latency**: Decoding multi-camera high-fps video feeds on standard hardware creates CPU bottlenecks and frame drops during live threat detection.
  * **Hardware Constraints**: Running heavy neural networks on edge hardware requires strict memory and latency optimization.

* 💡 **Technical Solution**:
  * Implemented multi-threaded frame buffers and **OpenCV CUDA backends** to pipeline video decoding directly to GPU memory.
  * Applied model quantization and TensorRT optimizations to deploy PyTorch vision models with low-latency object detection on **NVIDIA Jetson** boards.

* **Tech Stack**: `PyTorch` • `OpenCV` • `NVIDIA Jetson` • `Edge AI` • `Python`

#### 🧠 04. Visual Stress Detection System
> **Biomedical Signal Processing & Micro-Motion Analytics**

* 🛑 **Engineering Challenge**:
  * **Intrusive Hardware**: Conventional physiological stress monitoring relies on physical contact sensors attached to patients, causing discomfort and artificial stress elevated readings.
  * **Subtle Motion Detection**: Facial micro-tremors and subtle color fluctuations are imperceptible to standard frame-by-frame image classifiers.

* 💡 **Technical Solution**:
  * Engineered a non-invasive vision pipeline using dense **Optical Flow** to track sub-visual facial skin tremors from standard webcam streams.
  * Extracted temporal frequency signals from facial region-of-interest (ROI) tracking to compute physiological stress indicators without hardware attachment.

* **Tech Stack**: `Python` • `OpenCV` • `Optical Flow` • `Signal Processing` • `Scikit-Learn`
