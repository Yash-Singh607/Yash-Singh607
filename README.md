## 🧪 Featured Engineering Case Studies

<table>
  <tr>
    <td width="100%">
      <h3>🫁 01 · PulmoScan — AI Pulmonary Diagnostic System</h3>
      <p><i>Medical Computer Vision & Visual Interpretability</i> &nbsp; <img src="https://img.shields.io/badge/ROC--AUC-94.2%25-00D2FF?style=flat-square"/></p>
      <ul>
        <li>🛑 <b>Challenge:</b> Radiograph datasets suffer extreme class imbalance and low local contrast that hides early lesions.</li>
        <li>💡 <b>Solution & Impact:</b> Applied <b>CLAHE</b> contrast normalization and <b>Weighted Focal Loss</b> with transfer-learning architectures (ResNet/EfficientNet), reaching <b>94.2% ROC-AUC</b> and cutting false-negatives by <b>38%</b>. Integrated <b>Grad-CAM</b> heatmaps for transparent visual verification.</li>
        <li>🏷️ <b>Stack:</b> <code>PyTorch</code> · <code>OpenCV</code> · <code>Grad-CAM</code> · <code>Scikit-Learn</code> · <code>Python</code></li>
      </ul>
      <details>
        <summary><b>🔍 Deep architecture details</b></summary>
        <br/>
        <ul>
          <li><b>Preprocessing:</b> <code>CLAHE (Clip Limit=2.0, TileGridSize=8x8)</code> for X-ray contrast enhancement.</li>
          <li><b>Loss Function:</b> <code>Focal Loss (alpha=0.25, gamma=2.0)</code> to prioritize hard, ambiguous lesion samples.</li>
          <li><b>Interpretability:</b> Target-layer activations hooked into <code>Grad-CAM</code> for 224×224 attribution heatmaps.</li>
        </ul>
      </details>
    </td>

      <h3>🎭 02 · Emotion Drift Detection System</h3>
      <p><i>NLP & Sentiment Trajectory Dynamics</i> &nbsp; <img src="https://img.shields.io/badge/F1--Score-89.6%25-6C5CE7?style=flat-square"/></p>
      <ul>
        <li>🛑 <b>Challenge:</b> Static sentiment classifiers score utterances in isolation, missing cumulative emotional decay in multi-turn conversations.</li>
        <li>💡 <b>Solution & Impact:</b> Built a <b>temporal sliding-window</b> algorithm computing sentiment velocity and acceleration over consecutive utterances using fine-tuned <b>Hugging Face Transformer</b> embeddings (<b>89.6% F1</b>), escalating high-risk chats <b>4.2 minutes earlier</b>.</li>
        <li>🏷️ <b>Stack:</b> <code>Python</code> · <code>Hugging Face Transformers</code> · <code>PyTorch</code> · <code>Pandas</code></li>
      </ul>
      <details>
        <summary><b>🔍 Temporal math & pipeline details</b></summary>
        <br/>
        <ul>
          <li><b>Embeddings:</b> Fine-tuned transformer pooled-output vectors.</li>
          <li><b>Sliding Window:</b> Window size <code>w=3</code> tracking velocity vectors across message timestamps.</li>
          <li><b>Escalation Trigger:</b> Cosine-distance decay &gt; 0.45 triggers priority-queue routing.</li>
        </ul>
      </details>
